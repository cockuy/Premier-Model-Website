# Premier Model — Fashion Website

A fashion-inspired website built using HTML and CSS, featuring a modern editorial layout, fashion photography, and smooth scrolling animations.

## ✨ Features

- Modern fashion agency-inspired design
- Navigation bar with search icon
- Full-screen video hero section
- Animated horizontal image gallery
- Alphabet-based model navigation
- Fashion editorial section
- Hover effects on model updates
- Animated marquee text
- Responsive design for different screen sizes

## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS animations and transitions
- Remix Icon
- Google/remote image resources via Unsplash

## 📁 Project Structure

```text
premier-model-website/
├── index.html

```

## 🚀 How to Run Locally

1. Download or clone this repository.
2. Keep all referenced assets in the same folder as `index.html`.
3. Open `index.html` in your browser, or use the VS Code Live Server extension.
